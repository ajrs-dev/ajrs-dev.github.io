Rift Index

Next.js · TypeScript · React · Tailwind CSS · Riot Games API

League of Legends champion and player lookup. Browse every champion on the live patch with kits, base stats and skins, or look up any player's rank, champion mastery and recent matches across 17 regions.

  • Caching matched to how often data changes: finished matches for a week, champion data for 12 hours, rank and mastery for minutes, so requests stay inside Riot's rate limits.
  • Server-only API client. Importing it into browser code is a build error, so the API key can't leak into the bundle.
  • Requests fail soft, so one flaky endpoint doesn't blank a whole profile page.

Heartbeat

React · TypeScript · Node.js · Express · SQLite · Docker

Uptime and latency monitoring service. Add a URL and a scheduler checks it on an interval, tracks uptime and p95 response time, opens incidents, and streams results to open dashboards live. Each account can publish a public status page.

  • Server-side request forgery protection, because users choose the URLs the server fetches: validation on creation, address checks at connect time to stop DNS rebinding, and no redirect-following.
  • Incidents open after two consecutive failures (back-dated to the first) and close on recovery. Live updates use server-sent events.
  • scrypt password hashing, hashed server-side sessions, rate limiting, strict per-user data isolation.
  • 165 tests (Vitest, Supertest, Testing Library), CI on every push, and a multi-stage Docker image that is smoke-tested in CI.

TaskFlow

React · TypeScript · Vite · Node.js · Express · SQLite · Vercel

Full-stack Kanban task manager. Create boards, add lists and cards, and drag cards within and between lists with the order saved across refreshes.

  • Bcrypt-hashed passwords and JWT sessions, with protected routes on both the API and the front end.
  • Every request body validated with Zod before it reaches the database.
  • Backend integration tests (Vitest and Supertest) and GitHub Actions running typecheck, build and tests on every push.
  • One Express app that runs as a local server or as a Vercel serverless function.
